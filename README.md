# Food Delivery Analysis

Analysis of 41,953 food delivery records to understand what affects delivery time, using Python, MySQL, Excel and Power BI.

## Project Overview

Delivery time is a key measure of service quality for food delivery platforms. In this project I cleaned a food delivery dataset, analyzed it with Python (Pandas) and SQL, and built Power BI dashboards to show how delivery time changes with traffic, city, weather, vehicle condition and order type.
